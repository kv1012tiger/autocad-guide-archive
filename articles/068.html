【奇摩知識+ 請問autocad如何存成pdf檔案】

Tiger&蘋果爸2006/04/14 12:28:08

各位高手
想請問一下 ，如何將autocad存成pdf檔，
因為不是每一台電腦都有cad，聽說能這樣處理
有人可以告訴我該 如何使用嗎？
http://tw.knowledge.yahoo.com/question/?qid=1306041403223&r=w

必須安裝以下版本,才能列印出圖成PDF。
Adobe Acrobat 7.0 Standard中文標準版
Adobe Acrobat 7.0 PRO中文專業版

如果你的考量只是希望在沒有CAD程式,但是希望能讀取CAD.
建議出圖成(DWF) 檔。可以使用 Autodesk™ DWF™ Viewer 來檢視與出圖出版的電子圖面集。
請至台灣歐特克網站下載,Autodesk™ DWF™ Viewer
http://www.autodesk.com.tw/adsk/servlet/home?siteID=1170616&id=2501735

*********************************************************************
出版的圖面集是從原始圖面建立的圖紙出圖的數位對等項。 任何人都可以使用 Autodesk DWF Viewer，檢視或出圖儲存為 Design Web Format™ (DWF™) 檔的圖面集。 使用 Autodesk DWF Viewer，可以開啟、檢視以及列印所有 DWF 檔案格式與其它點陣式格式的影像。 您可以平移、縮放與檢視個別圖紙及視埠。 您也可以檢視圖層資訊、圖紙與圖紙集性質、圖塊資訊和屬性，以及自訂性質，前提是 DWF 檔中包含這些資訊。 當您在檢視器中的 DWF 幾何圖形上移動游標時，具有關聯資料的物件會以紅色亮顯效果顯示。

DWF 格式圖面集的接收者無需擁有或瞭解該程式。 無論在世界的哪一個地方，他們都可以使用 Autodesk DWF Viewer 檢視與列印高品質的配置。

您可以使用此程式建立 Design Web Format (DWF) 檔。 DWF 檔為 2D 向量檔，您可以使用它在全球資訊網或企業網路上出版圖面。 每個 DWF 檔可以包含一張或多張圖紙。

任何 Autodesk&reg; DWF™ Composer 或 Autodesk&reg; DWF™ Viewer 的使用者，均可開啟、檢視與出圖 DWF 檔。 使用 Autodesk DWF Composer 或 Autodesk DWF Viewer，還可以在 Microsoft&reg; Internet Explorer 5.01 或更高版中檢視 DWF 檔。 DWF 檔能夠支援即時的平移和縮放，也能控制圖層和具名視景的顯示。
